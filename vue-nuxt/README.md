# Nuxt Vue Exercises

Proyecto de ejercicios de Vue 3 y Nuxt 4 realizado durante la formación frontend de Alebat.

Todos los ejercicios de Vue y Nuxt se desarrollarán sobre este mismo proyecto, ampliándolo progresivamente.

## Tecnologías

- Nuxt 4
- Vue 3
- TypeScript
- Tailwind CSS v3
- Pinia
- pnpm
