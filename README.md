# practicas-frontend

Repositorio destinado a los ejercicios de fundamentos frontend realizados durante la capacitación.

En este repositorio se trabajarán ejercicios de HTML, CSS, JavaScript, Tailwind CSS, TypeScript y APIs.

## Flujo de trabajo

Cada ejercicio se gestionará mediante un Issue, una rama asociada y un Pull Request hacia `main`.

Los commits seguirán la convención Conventional Commits y no se realizarán commits directamente sobre `main`.
